# AI Crafting Table Enhanced

Enhanced development fork of [AI Crafting Table](https://github.com/AlexLee1235/AICraftingTable).

Original project: [AlexLee1235/AICraftingTable](https://github.com/AlexLee1235/AICraftingTable), branch `dev`.

Target Minecraft version: 1.20.1 (Forge 47), Java 17.

## Enhancement direction

The goal is to expand generated content beyond fixed item/block attributes toward safe, declarative gameplay behaviors (for example, projectiles, entities, machines, fuel, energy, heat, and multi-part mechanisms).

Generated descriptions must be translated into validated behavior specifications executed by registered mod systems. Arbitrary AI-generated Java code will not be executed.

## Status

Repository access has been configured. The original source tree still needs to be imported and the enhanced implementation built and tested.
